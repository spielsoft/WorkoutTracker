# Historical App Store Notes

This filename is retained only to prevent old links from silently resolving to
missing content. Its former release plan described an obsolete authorization
and owner-specific configuration design. It is historical, non-authoritative,
and must not be used as build, OAuth, signing, testing, or release evidence.

Current source-MVP guidance is derived from checked-in configuration and lives
in:

- [`BUILDING.md`](BUILDING.md) for clone-to-run setup, platform status, and
  clean release builds;
- [`docs/google_sheets_development_auth.md`](docs/google_sheets_development_auth.md)
  for builder-owned Google, OAuth, bundle, and signing configuration;
- [`docs/testing.md`](docs/testing.md) for local and opt-in live validation.

App Store submission and centralized OAuth verification are outside the source
MVP. The future Google Picker authorization work is governed separately and is
not implemented by these notes.
