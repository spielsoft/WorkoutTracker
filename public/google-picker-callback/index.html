Google Picker callback

This static page receives the Google Picker spreadsheet selection result for /google-picker-callback/ and shows the next step.

Malformed callback

The callback result could not be read. Return to WorkoutTracker and try choosing the spreadsheet again.

Open WorkoutTracker

Callback Contract

  • Success uses state and comma-separated selected spreadsheet ID values from the query string or URL fragment. Accepted ID parameters are picked_file_ids, picked_file_id, picked_folder_ids, picked_folder_id, file_ids, file_id, folder_ids, folder_id, ids, and id.
  • Selection cancelled is represented by error=access_denied.
  • Picker error states are represented by an error value other than access_denied.
  • Missing request state is rejected before any selected spreadsheet ID is accepted.
  • State mismatch is rejected when the returned state differs from the browser-side expected state stored at workoutTrackerGooglePickerState in sessionStorage.
  • This page does not store workout data or act as an app backend.

Firebase Hosting serves this callback artifact as a static page only.
